THE TAG FIELD GUIDE — HTML REFERENCE

A working reference to fifteen HTML elements: what they mean, how to write them, and what they produce.

Tag Name Purpose Syntax Output
<h1> to <h6> Headings Define six levels of section headings for page structure. <h1>Title</h1> Large section heading
<p> Paragraph Wraps a block of text as a paragraph with automatic spacing. <p>Text</p> Paragraph block with margins
<br> Line Break Inserts a single line break inside text (self-closing). Line 1<br>Line 2 Line break without new paragraph
<hr> Thematic Break Draws a horizontal line to signal a thematic section break. <hr> Horizontal thematic dividing line
<strong> Strong Importance Semantically marks text as having strong importance (bold). <strong>Warning</strong> Bold text indicating importance
<em> Emphasis Marks text with stress emphasis and changes meaning (italics). <em>actually</em> Italics text with stress emphasis
<a> Hyperlink Creates a hyperlink to another page, file, or location. <a>Link</a> Clickable hyperlink
<img> Image Embeds an image into the page (self-closing). <img> Embedded image placeholder
<ul> Unordered List Creates a bulleted list where order does not matter. <ul><li>Item</li></ul> Unordered bulleted list
<ol> Ordered List Creates a numbered list when sequence or ranking matters. <ol><li>Step</li></ol> Ordered numbered list
<li> List Item Defines a single item inside a list (<ul>, <ol>, or <menu>). <li>Item text</li> Individual list item element
<table> Table Container Defines a data table as a grid of rows and columns. <table>...</table> Grid container for tabular data
<tr> Table Row Defines one horizontal row inside a table. <tr><td>Cell</td></tr> Single horizontal table row
<td> Standard Cell Defines a single standard data cell inside a table row. <td>Data</td> Standard data table cell
<th> Header Cell Defines a header cell for a table column or row (bold & centered). <th>Header</th> Bold & centered column/row header
