THE TAG FIELD GUIDE — HTML REFERENCE

A working reference to fifteen HTML elements: what they mean, how to write them, and what they produce.

Tag Name Purpose Syntax Output
<h1> to <h6> Headings Define six levels of section headings for page structure. <h1>Title</h1> Title (rendered as a large heading)
<p> Paragraph Wraps a block of text as a paragraph with automatic spacing. <p>Text</p> Text (rendered as a distinct paragraph block)
<br> Line Break Inserts a single line break inside text (self-closing). Line 1<br>Line 2 Line 1
Line 2 (forced line break)
<hr> Thematic Break Draws a horizontal line to signal a thematic section break. <hr> A horizontal dividing line across the page
<strong> Strong Importance Semantically marks text as having strong importance (bold). <strong>Warning</strong> Warning (rendered in bold)
<em> Emphasis Marks text with stress emphasis and changes meaning (italics). <em>actually</em> actually (rendered in italics)
<a> Hyperlink Creates a hyperlink to another page, file, or location. <a>Link</a> Link (displayed as standard text without an href)
<img> Image Embeds an image into the page (self-closing). <img> Broken image icon or empty image element
<ul> Unordered List Creates a bulleted list where order does not matter. <ul><li>Item</li></ul> • Item (bulleted list)
<ol> Ordered List Creates a numbered list when sequence or ranking matters. <ol><li>Step</li></ol> 1. Step (numbered list)
<li> List Item Defines a single item inside a list (<ul>, <ol>, or <menu>). <li>Item text</li> • Item text (rendered list item element)
<table> Table Container Defines a data table as a grid of rows and columns. <table>...</table> An empty grid container structure
<tr> Table Row Defines one horizontal row inside a table. <tr><td>Cell</td></tr> A single horizontal row containing "Cell"
<td> Standard Cell Defines a single standard data cell inside a table row. <td>Data</td> Data (inside a standard table cell)
<th> Header Cell Defines a header cell for a table column or row (bold & centered). <th>Header</th> Header (rendered bold & centered)
