THE TAG FIELD GUIDE — HTML REFERENCE

A working reference to fifteen HTML elements: what they mean, how to write them, and what they produce.

Tag Name Purpose Syntax / Key Attributes
<h1> to <h6> Headings Define six levels of section headings for page structure. Syntax: <h1>Title</h1>
Attributes: id
<p> Paragraph Wraps a block of text as a paragraph with automatic spacing. Syntax: <p>Text</p>
Attributes: class, id
<br> Line Break Inserts a single line break inside text (self-closing). Syntax: Line 1<br>Line 2
Attributes: None
<hr> Thematic Break Draws a horizontal line to signal a thematic section break. Syntax: <hr>
Attributes: None (styled with CSS)
<strong> Strong Importance Semantically marks text as having strong importance (bold). Syntax: <strong>Warning</strong>
Attributes: Global attributes
<em> Emphasis Marks text with stress emphasis and changes meaning (italics). Syntax: <em>actually</em>
Attributes: Global attributes
<a> Hyperlink Creates a hyperlink to another page, file, or location. Syntax: <a href="URL">Link</a>
Attributes: href, target="_blank", title
<img> Image Embeds an image into the page (self-closing). Syntax: <img src="file.jpg" alt="Desc">
Attributes: src, alt, width, height
<ul> Unordered List Creates a bulleted list where order does not matter. Syntax: <ul><li>Item</li></ul>
Attributes: class, id
<ol> Ordered List Creates a numbered list when sequence or ranking matters. Syntax: <ol><li>Step</li></ol>
Attributes: start, type, reversed
<li> List Item Defines a single item inside a list (<ul>, <ol>, or <menu>). Syntax: <li>Item text</li>
Attributes: value
<table> Table Container Defines a data table as a grid of rows and columns. Syntax: <table>...</table>
Attributes: border (legacy)
<tr> Table Row Defines one horizontal row inside a table. Syntax: <tr><td>Cell</td></tr>
Attributes: Global attributes
<td> Standard Cell Defines a single standard data cell inside a table row. Syntax: <td>Data</td>
Attributes: colspan, rowspan
<th> Header Cell Defines a header cell for a table column or row (bold & centered). Syntax: <th>Header</th>
Attributes: scope
